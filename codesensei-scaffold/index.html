Plain-English summary

This is a full-stack expense tracker. Requests come into index.js, pass through auth middleware, and hit one of three route groups (auth, expenses, dashboard). Each route delegates to a service file that holds the actual logic, which talks to the database layer. The frontend is a set of React components that call these APIs and render charts. If you're changing behavior, the service files are almost always where the real logic lives — the routes are just thin wrappers.

Local setup checklist

  • Node.js 20+ and pnpm installed
  • Clone repo, run pnpm install
  • Copy .env.example to .env — ask your lead for the Plaid sandbox key
  • Run pnpm db:migrate to set up local Postgres
  • Run pnpm dev — app should be live on localhost:3000

Common failure point

Most first-run failures happen at the migration step because of a missing local Postgres instance. Fix: docker compose up db before running migrations.
